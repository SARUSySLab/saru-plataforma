# SARU Systems Lab

Repositório da empresa. Aqui moram as decisões, os requisitos da empresa e das famílias de
produto, o processo de trabalho e a documentação de física validada. Código de produto vive
nos repositórios de cada família (hoje, `SaruSysLab/saru-poc-trackday`).

Por onde começar, nesta ordem:

1. `docs/requisitos/00-guia-de-leitura.md`, os termos em uma linha cada.
2. `docs/requisitos/01-problema-e-objetivos.md`, por que a SARU existe.
3. `docs/decisions.md`, o que já foi decidido e o que está pendente.
4. `CLAUDE.md`, as regras que qualquer pessoa ou agente segue aqui.

Idioma: português. Fluxo: GitHub Flow, `main` protegida, branch por tarefa, merge só por PR.
