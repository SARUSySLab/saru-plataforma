# Runbook: GitHub Flow

1. Criar branch curta a partir de `main`.
2. Fazer commits Conventional Commits.
3. Abrir PR pequeno e descritivo.
4. Aguardar CI e CODEOWNERS.
5. Corrigir feedback.
6. Squash merge ou merge conforme regra do repo.
7. Apagar branch.

Sem self-merge em fisica, contratos, auth, seguranca ou claims comerciais.
