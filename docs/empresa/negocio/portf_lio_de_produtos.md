## 2. Portfólio de Produtos
O ecossistema é composto por produtos modulares que acessam o mesmo hub de dados:
- **SARU Analyzer (SA):** Ferramenta de telemetria fina voltada para engenheiros de pista.
- **Lap Time Simulator (LTS):** Otimização quasi-estática (QSS) para *setup* veicular.
- **SARU Dynamics (SD):** Simulação acausal transiente de alta fidelidade (14-DOF).
- **Módulos Corporativos:** Integrações planejadas para B2B, incluindo faturamento (CRM) e controle de ativos (ERP).
